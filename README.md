# 摘石榴 · picking-typing

一个由小小创作者提出玩法的打字游戏：石榴亮起黄光，按下它上面的字母，果实就落进篮子。全部摘完，一局成功。从 F、J 开始，共八局，逐步加入更多字母。

## 本地试玩

无需安装依赖。在项目目录运行：

```sh
python3 -m http.server 4174
```

在电脑浏览器打开 `http://localhost:4174`。连接实体键盘，切换到英文输入法；也支持点击亮起的石榴或屏幕键盘。

## 这一版

- 宣纸暖色、灰瓦庭院、远山和石板地；棕色树干与藤编果篮。
- 放大的自然红石榴，红褐花萼和果皮细斑；黄光环绕果实，不遮盖红色。
- 果实保持原尺寸下落，在篮中逐层堆积；篮前壁遮住底层果实，最后一颗落稳后才成功。
- 彩色尖叶、叶脉及地面落叶；支持系统的“减少动态效果”。

代码审查与修复说明见 [docs/REVIEW.md](docs/REVIEW.md)。

## 验证

需要 Node.js 18 或更新版本：

```sh
node --check js/game.js
node --test tests/geometry.test.mjs
```

测试覆盖全部八局、篮内坐标、落果结束时机、重开、键盘输入和存储不可用等情况。还需在实际 iPad 和外接键盘上检查触摸、声音及横竖屏表现；桌面浏览器的尺寸检查不能代替真机测试。

## 文件

- `index.html`：古风庭院、树干、叶子和果篮的原创 SVG 场景。
- `css/game.css`：横竖屏布局、石榴与高亮、篮内遮挡和轻量动画。
- `js/game.js`：八局练习、键盘输入、果实绘制、下落和音效。
- `tests/geometry.test.mjs`：玩法与几何回归测试。

游戏没有账号、广告、外部字体或第三方运行依赖。静音设置保存在当前浏览器；不会上传打字内容。目前这一版尚未配置主屏幕安装及离线缓存，GitHub 仓库链接本身也不是可安装的游戏链接。
